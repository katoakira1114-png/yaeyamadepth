# 八重山 水深マップ（スマホ用Webアプリ）

現在地と、その地点の推定水深を表示します。一度ダウンロードしておけば、圏外（機内モード）でも動きます。iPhone・Android両方で使えます。

> **注意**: 水深は海図と衛星画像から作った推定値です。誤差があり（浅場で約2m、15m以深は海図のみ）、潮位補正もありません。航行や潜水の安全判断には使えません。
> 海図の出典は海釣図V（著作権は提供元）、衛星画像は Copernicus Sentinel-2（ESA）、港と海岸線は © OpenStreetMap contributors。
> **海図の著作権は提供元にあります。誰でも見られる場所に置く前に、許諾を確認してください。** 自分たちだけで使う場合も、URLを人に教えないなどの配慮をしてください。

## フォルダの中身
| ファイル | 内容 |
|---|---|
| index.html / app.js | アプリ本体（外部ライブラリなし） |
| sw.js | 圏外で動かすための仕組み（Service Worker） |
| manifest.webmanifest, icon-*.png, apple-touch-icon.png | ホーム画面用の名前とアイコン |
| data/ | 水深データ（約23MB、242ファイル） |

## 置き方（どれか1つ）
スマホの位置情報と圏外動作は、**https:// で始まるURL** でないと動きません。下のどれでも無料でHTTPSになります。

### A. GitHub Pages（おすすめ）
1. GitHub で新しいリポジトリを作る（例: `yaeyama-depth`）。**著作権の都合で、可能なら Private（非公開）に**。※ Private リポジトリで Pages を使うには有料プラン（GitHub Pro 等）が必要です。無料プランでは Public になり、誰でも見られる状態になります。
2. この `app` フォルダの**中身**（index.html などと data フォルダ）をリポジトリの一番上にアップロードする（ブラウザの「Add file → Upload files」にフォルダごとドラッグで可）。
3. リポジトリの Settings → Pages → 「Deploy from a branch」、Branch を `main` / `/(root)` にして Save。
4. 1〜2分後に `https://<ユーザー名>.github.io/yaeyama-depth/` で開けます。

### B. Cloudflare Pages
1. Cloudflare にログイン → Workers & Pages → Create → Pages → 「Upload assets（直接アップロード）」。
2. この `app` フォルダをドラッグして Deploy。`https://<名前>.pages.dev/` で開けます。
3. 人に見せたくない場合は Cloudflare Access（Zero Trust、無料枠あり）でメールアドレス認証をかけられます。

### 手元で試すだけなら
パソコンで `app` フォルダに移動して `python -m http.server 8000` を実行し、同じパソコンのブラウザで `http://localhost:8000/` を開く（スマホからはHTTPSでないので位置情報が使えません）。

## スマホへの入れ方
- **iPhone**: Safari でURLを開く → 共有ボタン → 「ホーム画面に追加」。**その後、ホーム画面のアイコンから開いて**、下向き矢印ボタン →「ダウンロード」。（Safariとホーム画面のアプリは保存場所が別なので、アイコンから開いた状態で保存してください）
- **Android**: Chrome でURLを開く → メニュー →「ホーム画面に追加」（または「アプリをインストール」）。アイコンから開いて「ダウンロード」。
- 初回は位置情報の許可を求められるので「許可」。
- iPhone は、しばらく使わないと保存データを自動で消すことがあります。消えていると起動時に「保存データが消えています」と出るので、電波のある所で再ダウンロードしてください。出かける前日に一度開いて確認するのがおすすめです。

## 画面の見方
- 上: 現在地の水深（m）、位置の精度（±m）、データの細かさ（10m格子 / 20m格子）、緯度経度。陸の上では「陸」、範囲外は「データなし」。
- 地図: 色が水深（明るいほど浅い）、細い線が等深線（浅場は1m・5m・10mごと、深場は50mごと）、ベージュが陸、灰色が堤防・桟橋。指2本で拡大縮小、1本で移動。タップするとその地点の水深と、現在地からの距離。
- 右下のボタン: 現在地に戻る（青いときは現在地を追いかける）／ダウンロード／注意と出典。

## 追加機能（2026-10-24）
- **立体表示**（右の立方体ボタン）: 現在地のまわり（±6km、中心±1.5kmは10m格子）を立体で表示。現在地の印は海面（0m）に浮かび、海底まで線が伸びます。指で回転・拡大、「高さ×」で起伏の強調を変更。海底をタップすると水深。重いので、使うときだけ読み込みます。
- **航跡**（波線ボタン）: アプリを開いている間、自動で記録（日ごと、端末内に保存）。地図に黄→赤（時間の古い→新しい）の線で表示。日付を選んで過去の日も表示、GPXで書き出し。「画面を消さない」をオンにすると記録が途切れにくくなります（画面を消す・他のアプリに切り替えると記録は止まります）。
- **地点**（ピンのボタン）: 「現在地を登録」または地図をタップして「ここを地点登録」。名前とメモ（🎤ボタンかキーボードのマイクで音声入力）。ピンをタップするとメモを表示。GPXで書き出し。
- **写真**（カメラのボタン）: アプリから撮ると、撮った場所に紫の印が付きます。写真アプリの写真は「航跡と写真」→「写真を読み込む」で、写真の位置情報、なければ撮影時刻と航跡から場所を付けます。
- 航跡・地点・写真は端末の中だけに保存されます（サーバーには送りません）。機種変更などに備えて、ときどきGPXで書き出してください（写真はGPXに入りません）。
- 音量ボタンで音声入力を始める機能は、Webアプリの制約で作れません。

## データやアプリを更新したとき
- `data/` を差し替えたら、アプリの「ダウンロード」画面で「最新に更新」を押すと取り直します。
- データの形式を変えたときは `sw.js` の `DATA` の名前（`yaeyama-data-v1`）を `v2` などに変えると、古い保存データが自動で消えます。その場合は `app.js` の `DATA_CACHE` も同じ名前に。
- index.html / app.js を直した場合は、次の次の起動から新しい版になります（1回目の起動で裏で取り込みます）。

## 技術メモ
- 座標は UTM 51N（EPSG:32651）。緯度経度からの変換は app.js 内の UTM 式（pyproj と 1cm 以内で一致を確認）。
- 水深は PNG 右半分の合成水深C（0.1m単位）。10m格子があれば優先、なければ20m格子。
- 動作確認（2026-10-24、Chromium + Playwright、位置を偽装）: 石垣港付近 24.3350N,124.1555E → 5.2m、名蔵湾 24.405N,124.13E → 2.8m、名蔵湾の沖 24.41N,124.10E → 21.0m。Python で直接PNGを読んだ値と一致。ダウンロード後、オフラインにして開き直しても表示・水深表示・タップができることを確認。
